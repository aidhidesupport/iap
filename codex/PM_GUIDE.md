# PMガイド — 依頼・共有・判断

2026-09-22 / PMと開発者は別々の人

PMに専用ツールの導入やJSONの編集は求めません。既存のチャットで依頼と共有文をやり取りします。通常の修正は開発者とCodexが進めます。

## 依頼で伝えること

```text
目的：誰の何を解決したいか
渡してほしいもの：成果物と確認結果
完成条件：何を確かめれば完成と言えるか
対象外：今回扱わないこと
共有先・返答の目安：どこで、いつ確認するか
```

不明な条件は不明として残します。変更が必要になったら、その理由と新しい条件を開発者へ伝えます。

## 届いた共有文を見る

| 項目 | 確認すること |
|---|---|
| 目的・条件の版 | 今回合意した依頼に対する報告か |
| 進捗と根拠 | 何を確認できたか。未確認が残っていないか |
| 残り・次の一手 | 次に開発者側で何をするか |
| 確認事項 | PMの判断が必要か、進捗の共有だけか |

正常入力を確認し、不正入力の検証が残っているだけなら通常の作業途中です。すべての共有に承認の返答を求める運用にはしません。

## 判断を返す場面

目的・完成条件・対象範囲を変える必要がある場合は、PMが判断を返します。成果を受け入れる判断も、Codexの評価とは分けて行います。

```text
対象：確認案v2／今回の検証報告
判断：今回は認証を追加せず、CSVの検証を続ける
変更する条件：なし
追加で確認したいこと：不正入力の行番号と、合計を出さないこと
```

条件を変えるなら開発者が記録の版を更新します。前の版への回答は、新しい成果の承認として使いません。PMの回答の自動回収・自動反映・承認画面はまだありません。

## 最初の試行で残すこと

30〜60分で途中成果を確認できる一案件を選びます。共有文を読む・確認する実作業時間、分かりにくかった点、次も使いたいかを短く記録してください。返信までの経過時間を、PMが作業した時間とは数えません。不明な時間は不明のまま残します。
